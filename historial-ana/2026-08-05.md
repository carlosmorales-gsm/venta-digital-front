# ANA — 2026-08-05 — Frontend Venta Digital

## Objetivo del día

Levantar el frontend desde el scaffold Vite/Vue e implementar sesión + pantallas base para vendedor, monitor y admin, con diseño GSM y soporte responsive.

## Hecho

- Dependencias: `vue-router`, `pinia`, `axios`.
- Identidad GSM: tokens CSS, fuentes Roboto/Recline, logos copiados de `gsm-website`.
- Auth store + HTTP client con refresh automático (monitor/admin).
- Pantallas:
  - Home de elección de acceso
  - Login vendedor (celular → PIN WhatsApp)
  - Login monitor/admin (usuario/contraseña)
  - Listado “Mis ventas” del vendedor (consume `/sales/mias`, aún vacío)
  - Menú monitor filtrado por permisos
  - Admin alta/listado de usuarios
- Utilidad de timezone del navegador para mostrar fechas UTC en hora local.
- Guards de router por rol/permiso.
- `AGENT.md` con reglas para IAs.

## Decisiones

- Sesión vendedor sin refresh; al día siguiente debe volver a pedir PIN.
- Monitor/admin usan access + refresh persistidos en `localStorage`.
- Estructura por módulos de dominio para legibilidad.

## Diseño

- Referencia de marca GSM (colores/logos/fuentes), **identidad de layout propia**.
- No se replica el split-login ni el sidebar de NetPay.
- Login centrado + header/nav superior para la app autenticada.

## Ventas monitor/admin

- Monitor y Admin con permiso `ventas.ver` ven **todas** las ventas de vendedores.
- Front: ruta `/monitor/ventas` + ítem de menú/nav.
- API: `GET /api/sales/todas` (placeholder vacío por ahora).

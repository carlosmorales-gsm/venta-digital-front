# ANA — 2026-08-06

## Diálogos globales

- Prohibidos `alert` / `confirm` / `prompt` nativos.
- Sistema en `src/shared/ui/dialog/`:
  - `useDialog()` → API Promise
  - `VdDialogHost` en `App.vue`
  - Variantes: info, success, warning, danger
- Documentado en `AGENT.md`.

## Vite

- `server.open: true` para abrir el navegador al ejecutar `npm run dev`.

## Usuarios admin

- Crear / editar en el mismo formulario.
- Habilitar / deshabilitar con `useDialog` (confirm + alert).
- Endpoints: `PATCH /users/:id` y `PATCH /users/:id/active`.

## Bitácora (solo ADMIN)

- Ruta `/admin/bitacora` + ítem de menú lateral.
- Filtros: palabra clave (`q`), usuario (`actorUserId`), tipo de acción.
- API: `GET /audit-logs`.
- PDF según filtros: se genera en el front con `jspdf` (consulta listado filtrado).
